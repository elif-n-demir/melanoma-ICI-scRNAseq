# Technical notes

Supplementary documentation for the melanoma scRNA-seq reanalysis.

These notes define the methodological boundaries of the project and outline realistic validation strategies. They are not additional analyses.

## Documents

- [Methodological notes](methodological_notes.md): data type constraints, unit of replication, and validation strategy for the B-cell HLA class II signal.
- [Spatial/TLS future directions](spatial_tls_future_directions.md): spatial and histological validation strategy for B-cell/TLS-related hypotheses.
- [Multi-omics tumour-intrinsic future directions](multiomics_tumour_intrinsic_future_directions.md): future integration of the immune-cell signal with tumour-intrinsic features.

## Boundary

The main repository contains the completed single-cell transcriptomic reanalysis. The documents in this folder describe limitations, validation strategies, and future research directions. No additional analysis beyond the main repository has been performed.
- [Tumour–immune validation framework](tumour_immune_validation_framework.md): a literature-guided framework connecting exploratory patient-level single-cell observations with potential co-culture, molecular, soluble-factor, immunophenotyping and spatial follow-up strategies.
